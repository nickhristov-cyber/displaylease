# Images Folder

Place the following image files here:

| Filename     | Usage                                   | Notes                        |
|-------------|------------------------------------------|------------------------------|
| `logo.jpg`  | Header navigation logo                  | Recommended height: ~80–100px tall, transparent background preferred |
| `footer.jpg`| Footer logo                              | Same as logo or a white/light variant |
| `og-image.jpg` | Social media preview image (Open Graph) | Recommended: 1200×630px     |

## Logo fallback
If `logo.jpg` is not found, the site automatically displays the text logo:
**Display**<span style="color:#00c8ff">Lease</span>

So the site will work fine until you add the images.
